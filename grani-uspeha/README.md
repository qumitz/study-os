# Интерактивный комплекс «Грани успеха: Огранка»
### Мультиборд-приложение для мероприятия «День профмастерства»

Продакшн-ready интерактивное Single Page Application (SPA) для больших сенсорных экранов и интерактивных досок (мультибордов) с разрешением **4K (3840×2160)** и **Full HD (1920×1080)**.

В основе визуального ряда лежит **единый физический камень**, состоящий из внутреннего алмазного ядра и внешней каменной породы (24 сегмента). В ходе спектакля зрители своими глазами видят, как **реальные 3D-инструменты работают на сцене**, откалывая кусок за куском и превращая сырую породу в сияющий 58-гранный бриллиант!

## 🎮 Управление на мультиборде

- **Кнопка «УДАР ИНСТРУМЕНТОМ» (или тап по камню):** активирует удар молотка / шлифовку напильника / полировку с анимацией инструмента, звуком и высеканием искр!
- **1 палец (Drag):** свободное вращение камня в любом ракурсе.
- **2 пальца (Tap):** переход на следующую грань.
- **Горизонтальный свайп:** листание граней влево/вправо.
- **Клавиатура / кликер:**
  - `Space` / `ArrowRight` — вперед к следующей грани.
  - `ArrowLeft` — назад.
  - `KeyS` — удар инструментом.
  - `Digit 0–5` — прямой переход на грань 0..5.
  - `KeyD` — шторка программы концерта и суфлера.
  - `KeyC` — модальное окно «Слово директора и Награждение».
  - `KeyM` — звук вкл/выкл.
  - `KeyF` / `F11` — полноэкранный режим.
  - `KeyA` — скрытая панель оператора.
